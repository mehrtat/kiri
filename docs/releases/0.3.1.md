## New
- **The Windows installer is in the release again.** `Kiri-0.3.1-x86_64.msi`, with its update feed and `SHA256SUMS-windows`, is built from the tag on GitHub's Windows runners, next to the Linux packages. Its contents are as before: `bin\docker.exe`, `bin\kiri.exe`, Compose and buildx, `kiri-linux.tar.gz`, `setup-tools.ps1`. It is not Authenticode-signed yet, so SmartScreen asks before running it.
