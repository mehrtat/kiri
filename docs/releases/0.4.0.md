## New
- **`docker import`**: makes an image from a root filesystem tarball (#461).
- **zstd and gzip archives**: `docker cp`, `docker load` and `docker import` take zstd archives, and `docker load` takes gzip-compressed ones (#528, #579).
- **Every menu in the window is a searchable dropdown**, and a first-launch step that fails waits in a checklist instead of closing Kiri.

## Fixed and improved
- **Networks**
  - A container can leave its first network, as with Docker (#418).
  - A container's networks are searched by network name in DNS (#294).
  - A container on the default bridge that joins a user network resolves its names (#507).
  - The network id filter is a regular expression, so k3d finds its network (#448).
  - The address pool skips only on-link routes (#228).
- **Engine**
  - An empty `--entrypoint` clears the image's (#445).
  - `--add-host` overrides `host.docker.internal` (#428).
  - The ancestor filter matches the image a name means, not every tag of it (#451).
- **Compose:** Remove project takes it off the list, and an empty section says so every time.
- **Translations:** the Russian, Korean and Italian translations are corrected.
- **Tests:** the container-list save speed test passes on machines whose /tmp is a tmpfs.

Everything from 0.3.1 stays: Docker Hub mirrors with failover, system and `certs.d` registry trust, `kiri setup` on Linux, and the Windows installer built on GitHub.
